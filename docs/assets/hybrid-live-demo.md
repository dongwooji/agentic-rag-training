# 실제 웹 화면 녹화

README의 GIF는 **2026년 10월 22일 React 화면의 실제 서버 모드에서 질문을 전송하고, 새로 받은 답변과 근거 패널을 확인한 화면**을 캡처해 제작했습니다. 촬영 시작 시각은 한국 시간 19시 24분입니다.

## 질문과 결과

> 내 Deadlift (Barbell)의 처음 3세션과 최근 3세션 e1RM 중앙값을 비교하고, 점진적 과부하와 관련된 문헌 근거를 함께 설명해줘.

- 첫 질문이 `answer_ready`, `route=hybrid`로 완료됐습니다. 다른 질문을 반복 실행하거나 과거 저장 응답을 재생해 선택하지 않았습니다.
- 운동 기록 조회, Metric 계산, 문헌 검색이 모두 실행됐습니다.
- 처음 3세션의 e1RM 중앙값은 379.17, 최근 3세션은 414.17로, 약 9.23% 증가했습니다. 원본 정규화 기록에서 세션별 최고 Epley e1RM을 계산한 뒤 중앙값을 비교해 수치 일치를 확인했습니다.
- 답변은 실제 1RM과 추정치의 차이, 개인 기록만으로 원인을 단정할 수 없다는 한계를 함께 제시했습니다.
- 사용된 문헌은 2편의 논문에 속한 2개 청크입니다. Grader는 최초 검색의 근거를 충분하다고 판정했고 Recovery는 실행되지 않았습니다.
- 화면에 표시된 서버 처리 시간은 약 23.61초입니다. 이 API 필드는 서버의 초기 준비와 화면 조작을 포함한 전체 녹화 시간과 구분합니다.

## 녹화와 편집

실제 브라우저 캡처를 원래 시간 순서대로 연결했습니다. 질문 전송, 응답 대기, 답변 읽기, 근거 패널 열기와 스크롤을 포함합니다.

긴 대기 구간과 중복된 화면 이동을 생략하고, 일부 화면은 읽기 편의를 위해 표시 시간을 늘렸습니다. 캡처 영역 위에 촬영일과 대기 구간 단축 안내를 붙였습니다. 앱 화면의 내용, 답변 문장, 계산 수치와 근거 판정은 수정하지 않았습니다. 원문의 표현과 한계 안내도 그대로 표시했습니다.

웹 화면의 ‘전체 공개 응답 확인’에서 읽은 [공개 응답 원문과 캡처 기록](hybrid-live-demo-source.json)을 함께 제공합니다. 인증값이나 서버 내부 로그는 포함하지 않았습니다.

## 검증 범위

DB와 OpenAI를 실제로 호출한 단일 실행 사례입니다. 별도로 DB 인증과 OpenAI 연결도 확인했습니다. GIF 전체 프레임의 파일 읽기, 화면 가독성, 원본 기록과 계산 결과의 일치, 공개 응답 사본의 인증값 제외 여부를 확인했습니다.

이 사례는 사용 과정을 보여주는 데모입니다. 전체 질문의 답변 정확도나 독립적인 일반화 성능을 의미하지 않습니다. 기존 문헌·평가셋·Gold·연구 보고서와 기준선은 변경하지 않았습니다.
